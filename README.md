# 八角 · 币安持仓监控与美股波段工作台

监控币安代币持仓，研究对应底层美股的 **2～4 周波段**机会。每天最多筛选 3～5 个候选，条件不足时可以为零；不自动下单，不保证上涨。

## 全新 Web 控制台

旧 Web UI 已整体替换，不沿用旧布局、Vue 或 CDN。前端为独立 HTML/CSS/JavaScript，无前端安装或构建步骤。

- **持仓监控**：有效持仓、币安报价、未实现盈亏、持仓录入与编辑、止盈/止损、正向涨幅阶梯提醒、独立 AI 分析。
- **每日波段精选**：研究候选、规则依据、价位计算说明、失效条件、风险与来源；运行历史、分渠道重推、10/20 个后续交易日回顾。
- **推送记录**：区分成功、失败，支持状态筛选。研究运行成功不等于消息已送达。
- **配置中心**：FMP、兼容 OpenAI 接口的模型、飞书/企业微信、时区调度及默认监控偏好；币安凭据成对验证后独立保存。

桌面使用侧栏与工作台布局，手机使用顶部导航；包含加载、空数据、配置缺失、错误、重试与确认弹窗。页面不展示虚构行情或示例账户。

## 研究范围与方法

只覆盖原有标的池，不扫描整个美股市场：

| 币安代币对 | 底层美股 |
| --- | --- |
| NVDABUSDT | NVDA |
| TSLABUSDT | TSLA |
| AAPLBUSDT | AAPL |
| MSFTBUSDT | MSFT |
| AMZNBUSDT | AMZN |
| GOOGBUSDT | GOOG |
| METABUSDT | META |
| COINBUSDT | COIN |

SPY 仅作为市场与相对强弱基准，不作为候选。标的可交易性及数据权限需自行向供应商确认。

1. FMP 提供完整日线、季度财务、新闻与财报日历；缺失、过期或无权限的数据不能伪装成有效分析。
2. Python 执行可测试规则：至少 252 根日线，MA20/50/150/200、ATR、振幅/成交量收缩、相对 SPY 强弱及季度 EPS/营收增长；筛选分不是上涨概率。
3. 模型依据本地适配 Skills 和真实证据复核，允许否决全部候选；无模型或输出结构/来源不合格时不生成合成推荐。
4. 观察区间、研究止损与 2R 目标由规则计算，不是模型价格预测。Skills 为 VCP/CANSLIM 的有限因子适配，不是完整策略复刻，也未验证收益。

**两种价格不得混用：**持仓成本、现价、止盈止损使用币安代币 **USDT**；研究区间、研究目标与研究止损使用底层美股 **USD**。从候选录入持仓只带入代币对，不复制研究价格。行情读取失败显示缺失，不拿成本冒充现价或 0% 盈亏。

## 首次启动

需要 Python 3.11+；Docker 镜像使用 Python 3.11。

```bash
# 仅首次安装复制；已有 .env 时不要覆盖。
cp .env.example .env
# 编辑 .env：配置访问密码、数据源、模型与通知。
```

### Docker Compose

```bash
docker compose up -d --build
```

访问 `http://localhost:8000`；接口文档 `/docs`；健康检查 `/api/health`。`data/` 映射至容器 `/app/data`，请持久化并保护该目录。

### 本地运行

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

**只支持单实例、单 worker。**监控锁、AI 补充任务和运行恢复按此模式设计。不要启动多个进程共同监控同一数据库；开发重载也不要连接真实推送渠道。

## 配置顺序

1. 在 `.env` 设置 `ADMIN_PASSWORD`；浏览器使用用户名 `admin` 登录。不设置时页面和接口没有访问认证，必须限制可信网络访问；公网必须另配 HTTPS 与访问限制。
2. 配置 `FMP_API_KEY` 并确认订阅包含 stable 日线、季度财务、新闻及财报日历权限；**不保证免费套餐可用**。
3. 在配置中心填写模型 API Key、Base URL 和模型名，分别测试。支持兼容 OpenAI Chat Completions 的接口，不保证任意模型兼容。
4. 配置飞书或企业微信 Webhook。点击通知测试会实际发消息；飞书应用机器人配置独立，不替代每日研究的 Webhook 渠道。
5. 按需启用每日自动研究与推送，设置时间、IANA 时区、最多候选数（3～5）、最低分（40～100）及财报避让天数（0～14）。默认调度关闭，时间 21:30，时区 Asia/Shanghai。
6. 如需同步账户，使用只读币安 HMAC Key/Secret；不要授予交易、提现权限。在页面更换时提交当前 Secret 与完整的新凭据对，账户读取验证成功后才替换。

数据库非空配置优先于环境变量。FMP 密钥不回填，其他模型/应用 Secret 脱敏；留空保留原值。密钥及 Webhook **在 SQLite 中明文保存**，必须限制控制台、数据库、日志和备份访问；不要上传 `.env` 或数据库。浏览器不使用 localStorage/sessionStorage 保存密钥。

## 监控、调度与历史

- 风险扫描独立运行，约每 30 秒检查；单笔默认每 4 小时定期汇报。周期设为 0 只关闭定期汇报，不关闭风险监控。
- 止盈、止损、正向涨幅阶梯提醒与 AI 补充独立；风险消息不等待 AI。成功确认后才记录里程碑或汇报时间，失败允许重试。清空可选提醒价会真正移除该阈值。
- 新增、同步与重新启用已有持仓保留用户偏好；账户读取失败时取消同步，不清空持仓。停止监控不会卖出；后续账户同步可能重新启用仍持有的代币。
- 手动研究默认只更新结果，勾选“本次完成后推送”才发通知。自动研究按所选时区每天运行；错过设定分钟可在当日补跑，每日运行键持久化防止重启重复执行。
- 分析失败保留上次有效报告；隐藏候选不删除历史报告或回顾。通知按渠道和分段保存状态，重试跳过已确认成功的部分。
- 外部渠道已收取消息、进程却未记录成功时仍可能重复投递，不承诺 exactly-once。旧版日志的迁移默认状态不能独立证明历史送达。
- 回顾仅比较 10/20 个后续交易日真实收盘价与 SPY，不是已实现交易收益，不含滑点/费用，也不能作为策略收益回测。

### 自动发布（CI/CD）

向 `feat/swing-analysis` 推送会自动构建并测试镜像，发布至 GHCR，再部署到现有服务器；健康检查与数据保留检查通过后，仅清理本项目未使用的旧镜像。PR 只测试，不部署。流水线提供失败回滚，不覆盖服务器 `.env`、数据库或其他服务。

首次接入运行 `python3 scripts/setup_cicd.py --ssh-host zendesk-agent-server`，生成专用受限部署密钥并配置 Actions Secrets。完整流程、回滚与清理边界见 [CI/CD 说明](docs/cicd.md)。

原 `scripts/deploy.py` 仅保留作旧版本代码热更新工具。生产切换到镜像流水线后，不要与旧 Compose 源码挂载或热更新脚本混用；依赖变化由新镜像承担。

当前模块、API 与数据说明见 [波段分析架构](docs/swing-analysis.md)。旧的历史设计记录位于 `docs/superpowers/`，当前实现与本说明优先。

> 本项目仅为研究辅助，不构成投资建议。市场有风险，规则和模型均可能失效；所有交易由用户自行决策。
