# 研究与催化剂复核 — 项目适配 Skill

参考 Anthropic financial-services 的 idea-generation 与 catalyst-calendar 的研究流程，固定版本见 services/analysis_skills.py。本文为自主编写的项目适配，不复制或执行第三方脚本。

1. 目标为未来 2～4 周，不是 1～3 天超短线或长期估值。研究对象仅限明确映射的币安池底层美股。
2. 区分事实、预期与推断。事实引用给定 sources 的 ID；不要编造财报、订单、评级变化、新闻、日期或精确上涨概率。
3. 财报日历的未来事件是风险也是潜在催化剂，日期可能调整。临近财报禁入窗口由系统先行过滤；模型无权绕过。
4. 没有检索到新闻不等于利好，也不等于确认没有新闻。对风险、市场环境和证据时效给出解释。
5. 每个入选标的必须有清晰理由 reason、失效条件 invalidation、至少一条 risks 和引用 source_ids。可拒绝全部候选。
6. 底层美股 USD 分析价不等于币安代币成交价。不允许自动把分析价写入持仓止盈止损；不下单、不提供确定收益承诺。
7. 后续以实际 10/20 个交易日观察收益跟踪，结果不是含成本交易回测，也不代表未来表现。
