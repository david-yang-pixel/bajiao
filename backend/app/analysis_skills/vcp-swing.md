# VCP 波段筛选 — 项目适配 Skill

适用：原币安池对应底层美股，2～4 周条件性波段观察，不下单。
参考 tradermonty/claude-trading-skills 的 vcp-screener，固定来源版本见 services/analysis_skills.py。
以下为本项目自主编写的适配规则，不声称完整复刻原作者算法，也不声称通过回测。

1. 只使用已完成日线。由 Python 计算 MA20/50/150/200、ATR14、近高点、振幅收缩、缩量、20 日相对 SPY 强弱。
2. 优先观察向上中期趋势中靠近突破位且不过度延伸的股票。振幅收缩和缩量仅为 VCP 因子，不等同完整多阶段形态。
3. 所有入场区间、止损、2R 目标由给定价格计算，模型不得改写或另造数值，不保证目标实现。
4. 说明触发条件：需观察突破及量价确认，而非把未触发候选描述成已经买入。
5. 市场走弱、缺少确认、波动扩大时可拒绝。不能为了达到每天 3～5 只而硬凑。
6. 技术分是启发式规则分，不是校准上涨概率；不得把 High/百分比包装成胜率。
