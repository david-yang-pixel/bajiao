# 币安美股 (bStocks) 交易分析与持仓智能提醒机器人系统设计文档

- **创建日期**：2026-09-16
- **项目状态**：Design Approved / Ready for Implementation Planning
- **目标资产**：币安代币化美股现货资产（bStocks，如 `AAPLBUSDT`, `TSLABUSDT`, `NVDABUSDT`, `SPYBUSDT` 等）

---

## 1. 系统目标与核心价值

本系统旨在为美股 bStocks 交易者提供闭环的智能交易辅助服务：
1. **每日潜力股发现**：通过量化规则初筛结合 AI Agent 深度研判（K线技术面形态 + 新闻舆情 + 宏观分析），每天筛选出未来几天最具上涨概率的 3~5 只美股 bStocks。
2. **持仓追踪与智能巡检**：记录用户购入标的（成本、数量、目标价、止损线），支持设定固定汇报周期（如每 1/2 小时），自动化计算涨跌幅、持仓盈亏并播报当前最新价。
3. **阶梯暴涨/止损突变告警**：高频监控持仓行情，当涨幅达成阶段目标（如 +5%、+10%）或跌破止损位时，秒级触发加急通知。
4. **多端触达**：提供直观的 Web 控制台管理持仓与查看研报，并通过飞书/企业微信机器人将最新分析与盯盘提醒即时推送至用户手机与桌面。

---

## 3. 详细模块设计

### 3.1 模块一：bStocks 行情网关与数据获取 (Market Data Gateway)
- **协议对接**：
  - 优先调用 **币安 MCP (Model Context Protocol)** 或 Binance REST API 标准接口。
  - 获取交易对：所有后缀为 `BUSDT` 的代币化美股（标的示例：`AAPLB`, `TSLAB`, `NVDAB`, `MSFTB`, `AMZNB`, `GOOGLB`, `METAB`, `COINB`, `SPYB`, `QQQB`）。
- **核心功能**：
  - `fetch_ticker_price(symbol)`: 获取最新买卖撮合价。
  - `fetch_klines(symbol, interval, limit)`: 获取 1h、4h、1d K 线用于指标计算。
  - `calculate_indicators(df)`: 计算 MA5/MA20/MA60、MACD(12,26,9)、RSI(14)、成交量比率（Volume Ratio）与 24h 波动幅度。

### 3.2 模块二：AI 潜力股分析引擎 (AI Analysis Engine)
- **两阶段流水线设计**：
  1. **初筛器（Quantitative Screener）**：
     - 规则指标：
       - 均线多头排列（MA5 > MA20）
       - RSI 处于反弹强势区间（45 < RSI < 70）
       - MACD 金叉或柱状图放大
       - 近 24h 成交量显著放量（Vol > 1.3 * MA_Vol_5）
     - 得分排序，输出 Top 3~5 只候选标的。
  2. **AI Agent 深度研判（Deep Reasoning Agent）**：
     - 输入：候选标的多周期 K 线形态关键点位（支撑位、阻力位、均线分布）。
     - 工具调用：检索对应底层美股公司（如 NVDA / TSLA）的最新大事件、财报业绩预期、行业利好或分析师评级上调。
     - 输出结构化 JSON 报告：
       ```json
       {
         "symbol": "NVDABUSDT",
         "stock_name": "英伟达 (NVIDIA)",
         "bullish_score": 88,
         "confidence": "HIGH",
         "summary": "突破整理平台且24小时成交量放大1.8倍，叠加AI云业务最新财报预期利好。",
         "entry_range": [132.5, 134.0],
         "target_price": 145.0,
         "stop_loss_price": 127.5,
         "holding_horizon_days": "3-5天"
       }
       ```
- **自动化运行**：
  - 每日美股盘前定时自动执行一次，亦支持在 Web 控制台一键“即刻重新研判”。

### 3.3 模块三：持仓管理与复合告警调度引擎 (Position & Alert Engine)
- **持仓模型字段**：
  - `symbol`: 标的代码（如 `NVDABUSDT`）
  - `cost_price`: 买入成本价
  - `quantity`: 持仓股数
  - `buy_time`: 买入时间
  - `target_price`: 目标止盈价
  - `stop_loss_price`: 目标止损价
  - `report_interval_minutes`: 定期巡检间隔（默认 60 分钟，支持 15/30/60/120 分钟等配置）
  - `last_reported_at`: 上次巡检通知时间
  - `alert_milestones`: 已触发过的涨跌幅阶段（如 `[5, 10]`，防止同一阶梯重复震荡轰炸）
  - `is_active`: 是否正在盯盘监控
- **调度逻辑（双轨并行）**：
  1. **定时间隔巡检（Routine Check）**：
     - 触发条件：`now() - last_reported_at >= report_interval_minutes`。
     - 行为：拉取最新价，计算收益率与浮动盈亏，向飞书/企微机器人发送【持仓巡检汇报】。
  2. **高频异动巡检（Milestone & Stop Check）**：
     - 每 60 秒轮询持仓标的最新市价：
       - **阶段冲高**：涨幅突破 +5%、+10%、+15%、+20% 等阶梯，且未在已告警列表，触发【冲高突破加急告警】。
       - **触达目标价**：现价 >= `target_price`，触发【目标价达成提醒】。
       - **跌破止损线**：现价 <= `stop_loss_price`，触发【止损风险告警】。

### 3.4 模块四：机器人消息卡片与 Web 控制台 (Notifications & UI)
- **飞书 / 企业微信富文本卡片格式**：
  - **每日分析卡片**：包含日期、大盘综合情绪、Top 3 推荐股票列表、看涨逻辑要点、操作策略区间。
  - **巡检通知卡片**：
    - 标的：`NVDABUSDT (英伟达)`
    - 当前价格：`$142.50`
    - 成本与盈亏：`成本 $133.00 | 浮动盈亏 +$95.00 (+7.14%)`
    - 走势评估：`均线多头良好，距离目标价 $145.00 还差 1.75%`
  - **急报卡片（彩色醒目）**：红色预警（跌破止损）/ 绿色庆贺（突破阶段止盈目标）。
- **Web 控制台核心页面**：
  - `/` (首页/看板)：每日大盘推荐卡片流，直观展示上涨潜力预测与逻辑简报。
  - `/portfolio` (持仓监控)：当前持仓表格（现价、盈亏率动态刷新、提醒参数快捷修改弹窗、一键平仓/添加）。
  - `/settings` (配置中心)：配置 Binance MCP 地址/API 密钥、大模型 API Key（OpenAI/DeepSeek/Claude 等）、飞书/企微 Webhook 地址及测试发送。

## 4. 数据存储设计 (SQLite Models)

1. **`watchlist_candidates` (每日潜力推荐表)**:
   - `id`: 主键
   - `date`: 日期 (YYYY-MM-DD)
   - `symbol`: 股票代码
   - `stock_name`: 名称
   - `bullish_score`: 综合看涨评分
   - `technical_analysis`: 技术面分析文本
   - `news_catalyst`: 新闻与催化剂摘要
   - `entry_range`: 建议入场区间
   - `target_price`: 目标止盈价
   - `stop_loss_price`: 建议止损价
   - `raw_json`: 完整结构化数据
   - `created_at`: 创建时间

2. **`positions` (用户持仓跟踪表)**:
   - `id`: 主键
   - `symbol`: 股票代码
   - `stock_name`: 标的名称
   - `cost_price`: 买入均价
   - `quantity`: 持股数量
   - `target_price`: 目标止盈价
   - `stop_loss_price`: 目标止损价
   - `report_interval_minutes`: 提醒时间间隔（分钟）
   - `last_reported_at`: 上次汇报时间戳
   - `alert_milestones`: 已推送过的涨跌幅阶段（JSON 字符串）
   - `is_active`: 监控状态（1: 监控中, 0: 已结束）
   - `notes`: 备注

3. **`alert_logs` (通知历史日志表)**:
   - `id`: 主键
   - `position_id`: 关联持仓 ID（可为空）
   - `alert_type`: 告警类型 (`ROUTINE`, `BREAKTHROUGH`, `TARGET_HIT`, `STOP_LOSS`, `DAILY_PICK`)
   - `title`: 标题
   - `content`: 发送正文
   - `status`: 发送状态 (`SUCCESS`, `FAILED`)
   - `created_at`: 发送时间戳

4. **`system_configs` (系统配置键值表)**:
   - `key`: 配置键（如 `FEISHU_WEBHOOK_URL`, `WECOM_WEBHOOK_URL`, `BINANCE_API_KEY`, `LLM_API_KEY` 等）
   - `value`: 配置值
   - `updated_at`: 更新时间

## 5. 错误处理与防故障机制

1. **币安接口限流与网络异常**：
   - 数据网关内置指数退避重试（3 次）与本地内存缓存（TTL 30 秒），防止高频重复请求触发币安 429 限流。
2. **LLM 幻觉与超时防范**：
   - 所有技术指标均由 Python 脚本本地硬核计算，LLM 仅负责结构化推演研判，不依赖 LLM 计算价格数学题。
   - LLM 请求设定 30 秒超时时间，解析失败时安全降级为规则技术面简报。
3. **消息防疲劳（Anti-Spam）**：
   - 相同标的同方向的阶段告警设置 30 分钟冷却锁，避免价格在临界点反复震荡引起重复通知轰炸。

## 6. 测试与验证策略

1. **单元测试**：
   - 测试量化指标计算器（MA, RSI, MACD 等）在典型 K 线输入下的准确性。
   - 测试持仓收益率计算与阶段告警状态机转移逻辑。
2. **集成测试**：
   - 模拟行情变动：回放价格从 100 上涨到 105、110 以及跌至 95，验证定时巡检与阶梯加急告警能否按预期正确触发并写入日志。
   - 飞书/企微 Webhook 发送连通性测试。
3. **E2E / 页面联调**：
   - 控制台启动后，添加一条持仓记录，验证前后端数据通信与实时走势刷新。
